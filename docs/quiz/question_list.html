  2. It is a concave minimization problem; $\tilde{\boldsymbol x}(P) = (3)$, $z(P) = -1$
  3. It is a convex minimization problem; $\tilde{\boldsymbol x}(P) = (6)$, $z(P) = 26$
  4. It is a convex minimization problem; $\tilde{\boldsymbol x}(P) = (5)$, $z(P) = 11$
Explanation. $f(x) = 3\,(x - 3)^2 - 1$ is convex and $F = [2, 5]$ is convex: it is a convex minimization problem. The derivative $6x - 18$ vanishes at $x = 3$, which is feasible; $x = 3$ is a point of local minimum and hence optimal, because in a convex minimization problem every local minimum is optimal: $z(P) = -1$.

  2. It is a convex maximization problem; $\tilde{\boldsymbol x}(P) = (-1)$, $z(P) = 20$
  3. It is a concave maximization problem; $\tilde{\boldsymbol x}(P) = (3)$, $z(P) = -12$
  4. It is a concave maximization problem; $\tilde{\boldsymbol x}(P) = (1)$, $z(P) = 4$
Explanation. With $a = p - 1$ and $b = w - 1$ nonpositive, the inequality of cubes $\big(\lambda a + (1-\lambda) b\big)^3 \ge \lambda a^3 + (1-\lambda) b^3$ (the rest is linear) shows that $f$ is concave over $[-3, 1]$: it is a concave maximization problem. Consider the convex minimization problem $P$: $\min\{\, 2x_1^2 + 2x_2^2 - 12x_1 - 12x_2 \ \text{subject to}\ -2 \le x_1 \le 0,~ 2 \le x_2 \le 4 \,\}$. What are the optimal solution and the optimal value (with $\tilde{\boldsymbol x}(P)$ the optimal solution and $z(P)$ the optimal value)?
  1. $\tilde{\boldsymbol x}(P) = \begin{pmatrix} 0 \\ 3 \end{pmatrix}$, $z(P) = -18$
  2. $\tilde{\boldsymbol x}(P) = \begin{pmatrix} 3 \\ 3 \end{pmatrix}$, $z(P) = -36$
  3. $\tilde{\boldsymbol x}(P) = \begin{pmatrix} -2 \\ 2 \end{pmatrix}$, $z(P) = 16$
  4. $\tilde{\boldsymbol x}(P) = \begin{pmatrix} 0 \\ 2 \end{pmatrix}$, $z(P) = -16$
Explanation. Completing the squares, $f({\boldsymbol x}) = 2(x_1 - 3)^2 + 2(x_2 - 3)^2 - 36$. The point $\begin{pmatrix} 3 \\ 3 \end{pmatrix}$ is not feasible; each term depends on a single variable and is smallest when $3$ is brought back into $[-2, 0]$ and $3$ into $[2, 4]$: $\tilde{\boldsymbol x}(P) = \begin{pmatrix} 0 \\ 3 \end{pmatrix}$, $z(P) = -18$.

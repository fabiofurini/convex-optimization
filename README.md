# Convex Optimization

The lecture notes of the Convex Optimization course online: definitions,
theorems with their proofs, worked examples and exercises with solutions, with
the same numbering and colors as the PDFs.

**📖 Website: [fabiofurini.github.io/convex-optimization](https://fabiofurini.github.io/convex-optimization/)**

## Contents

| Part | Topics |
|---|---|
| 1 · Preliminaries | convex sets, functions of several variables (gradient, Hessian, level sets), norms, convex and concave functions, quadratic functions |
| 2 · Optimization problems | optimization problems, local and global optima, convex and concave problems |
| Exercises | exercises for every chapter, with worked solutions |

The lecture notes and the exercise books in PDF (two volumes each) can be downloaded from the
[downloads page](https://fabiofurini.github.io/convex-optimization/downloads/).

## How it is built

Pages, figures and PDFs are generated locally from the (private) LaTeX sources of the
notes; this repository contains the generated website (`docs/`, `mkdocs.yml`).
To preview it locally:

```bash
python3 -m pip install mkdocs-material
python3 -m mkdocs serve            # preview at http://127.0.0.1:8000
```
